# Liblib 本地视频下载器

一个只在本机运行的轻量工具：输入公开的 Liblib 作品链接，解析媒体地址并保存为 MP4。

## 启动

要求 Node.js 22 或更高版本。进入本目录后运行：

```bash
npm start
```

随后打开 <http://127.0.0.1:4173>，粘贴作品页链接，先点击“解析链接”，确认作品后点击“下载 MP4”。成品保存在 `downloads/`。

## 下载策略

- 页面存在公开原始 MP4 时，直接保存原文件，速度更快且不重复编码。
- 只有 HLS 时，调用 FFmpeg 合并并以 MP4 封装，不重新编码。此模式需要系统可执行 `ffmpeg`；也可通过 `FFMPEG_PATH` 指定其绝对路径。
- 界面会持续显示任务进度，完成后提供本地下载链接。

## 测试

```bash
npm test
```

## 使用边界

本工具仅接受 `www.liblib.tv/detail/<作品ID>` 格式，只处理详情接口公开返回、且来自受信任 Liblib 媒体域名的无 DRM 内容。它不读取登录凭据，不绕过付费、权限或技术保护。请仅下载你有权保存的内容，并遵守平台条款与版权要求。
